# The War of the Unheard Voice

A scrollable digital comic made for the **Buffalo Soldiers** assignment at i.c.stars, by Myia.

Inside every person is an army. This comic introduces eight soldiers (four personal, four professional), each personified by a Steven Universe character, and shows how they work together to win an interpersonal war: being interrupted when sharing ideas in staff meetings.

## What's inside

- **Chapter 1, Meet the Army:** each soldier's attributes, greatest strength, and weakness
- **Chapter 2, The War Is Declared:** the interpersonal challenge and the goal
- **Chapter 3, The Battle Plan:** before, during, and after the meeting
- **Chapter 4, Battle Formations:** fusions (Stevonnie, Garnet, Opal) and a relationship map
- **Chapter 5, Support and Clash:** when the soldiers help each other and when they don't
- **Chapter 6, Armor Up:** which soldiers need armor and where it comes from
- **Chapter 7, Maps for War and Peace**
- **Epilogue:** victory and image credits

## Built with

Plain HTML and CSS, no frameworks. Diagrams are hand-built SVG. Fonts (Bowlby One SC, Patrick Hand, Nunito) are self-hosted from Fontsource. The page supports light and dark mode and works on phones.

## View it locally

Open `index.html` in any web browser.

## Publish with GitHub Pages

1. Create a new public repository on GitHub (for example, `unheard-voice-comic`).
2. Upload everything in this folder: `index.html`, `README.md`, and the `img` and `fonts` folders.
3. In the repository, go to **Settings > Pages**.
4. Under **Build and deployment**, set Source to **Deploy from a branch**, pick the `main` branch and the `/ (root)` folder, and save.
5. After a minute or two, the site is live at `https://YOUR-USERNAME.github.io/unheard-voice-comic/`.
